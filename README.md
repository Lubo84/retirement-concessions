# Retirement concessions prototype

Cinematic member-facing concept with card navigation, state-specific next steps and a savings checklist. GitHub Pages serves the root of main.

## Original and rollback

The original presentation is available at ./original/ and the previous release is preserved on branch backup/pre-cinematic-2026-10-13. The cinematic update is a separate commit; reverting that commit restores the original homepage.

## Scope

General information and navigation, not an eligibility decision. Official information checked 12 October 2026. Recheck rules before relying on them. No analytics or member-account integrations. Optional checklist saving uses browser local storage. Reduced-motion preferences disable decorative animation.
