# Retirement concessions prototype

A member-facing concept for discovering Australian concession cards, following official next steps and recording confirmed savings. Includes a Marketing pitch view.

## Hosting

GitHub Pages serves the root of the main branch. Open index.html locally or use the published Pages URL.

## Scope

General factual information and navigation, not an eligibility assessment. Official information was checked on 12 October 2026. Recheck rules before relying on them.

Checklist entries can optionally be stored in the visitor's browser. Finder answers are not saved. No analytics or member-account integrations are included.
